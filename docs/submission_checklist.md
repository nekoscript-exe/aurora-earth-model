## Requisitos del proyecto
| Punto | Dato oficial |
|---|---|
| Demo obligatorio | Video de máx. 30 segundos **o** presentación de máx. 7 diapositivas (con portada e intro). Si se excede, no entra a Global Judging |
| Contenido del demo | Nombre del equipo, nombres de integrantes, reto elegido, imagen del proyecto, experiencia de usuario, cómo los datos abiertos de NASA hacen posible la solución |
| Idioma | Todo en inglés (página y materiales). Un video puede hablarse en otro idioma con subtítulos en inglés. Diapositivas en inglés |
| Hospedaje | Demo y archivos en sitio externo (YouTube, Drive, GitHub…) con enlace público, sin login, permisos ni registro |
| Imágenes en la página | JPG, PNG, GIF hasta 10 MB. No se suben videos ni documentos |
| Menores de 18 | Prohibido incluir imagen, video, audio o semejanza de menores de 18 años |
| Criterios de evaluación | Impact, Creativity, Validity, Relevance, Presentation |
| Participantes | Todos los integrantes confirmados en el mismo Local Event |
| Campos obligatorios | Project Name · High-Level Project Summary · Link to Project Demo · Link to Final Project · Detailed Project Description · Use of Super Intelligence (SI) · NASA Data · Space Agency Partner Data and Other References |
| Envío final | Marcar "Terms and Conditions" y "Confirm All Work is Original", y presionar "Submit for Judging". Se puede reenviar; cuenta el último guardado |
| Certificado | Solo si se presiona "Submit for Judging" a tiempo |
| Edición de la página | Usar el "Lock" y "Save Progress"; una persona edita a la vez |
